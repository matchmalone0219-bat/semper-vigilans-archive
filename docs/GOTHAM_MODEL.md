# 哥谭地图与城市沙盘

2026-10-05 · 三城区统一重绘、GCT 交通图层与沙盘

本轮只修改 `/places` 的互动地图及关联地图数据。三地区均可切换平面图与 3D 沙盘，并有可独立开关的 GCT 交通图层。

下城采用与上城、中城相同的 SVG 岸线、道路、绿地和建筑配色，657 个示意楼块与沙盘共用轮廓。已移除本次开发中先前使用的栅格提取脚本、几何数据及覆盖组件。保留原始底图媒体作为既有资料。

下城结合用户提供的 `Gotham_City_Map_%28Matt_Reeves%29.webp` 重绘主岛岸线、河道与南部三角区港区。设定原图原样保存，`settingSource` 记录 SHA-256、原图尺寸与共享坐标的对齐变换。原图未标注皇冠角边界；按用户确认将皇冠角标记和建筑占地移到南部 Tricorner 区域内，仍归入下城区。两岸重新描绘并在弯道采样平滑曲线，修复旧河岸在 North Docks 附近重合、河道过窄的问题；平面图和沙盘共用新轮廓。下城核心、皇冠角和南部港区共用一张平面图和沙盘，仍只有上城、中城、下城三个区域入口。冰山俱乐部与谜语人公寓调整到南侧桥头，保留隔街关系。

## 上城区与中城区

`src/data/gct-regions.json` 在同一张经透视校正的道具照片坐标系中记录三城区岛岸、绿地、交通线路和地点。记录原始照片 SHA-256、透视校正四角与 900×1360 的校正尺寸；三城区的展示裁切共享这一坐标基准。

上城覆盖 26 处交通地点（包含一个未署名换乘点），中城覆盖 24 处（包含一个停车标注）；两区均保留跨河接续站。同名的两个 Gotham Heights 站以西站、东站区分。照片中 Enosbury、Jergen St. 和 Caesar's Corner 的小字较模糊，暂标待辨，不将其读法升级为确定名称。四条过境线路分别为红、紫、棕、橙；Diamond District 至 Wayne Tower (Closed) 的关闭路段保留虚线与替代巴士说明。完整地点索引支持键盘、手机点击、详情和已有档案链接。

中城的大块中央绿地按 Robinson Park 绘制。上城 Arkham 站西侧大片用地按用户提出的解释画为阿卡姆病院区，斜纹和标签保留“推定”；交通图只给出站名与用地形状，不直接确证医院建筑群。Wayne Tower 模型使用原有塔楼模板，在站点附近作示意占地；新增阿卡姆模型有分开的院翼、中央体块与庭院。

`src/data/gct-buildings.json` 提供上城 716、中城 729 个普通建筑轮廓及道路面。道路是受岛岸、公园、院区和站点约束的示意设计，不是从交通照片恢复出的官方街道图纸。建筑沿局部街区边界布置，大小、朝向、凹口、院落与高度有差异；公园、病院区和塔楼示意占地排除普通楼块。没有在整岛套统一坐标网格。

`src/lib/gct-building-plan.ts` 将同一组道路和建筑数据用于平面 SVG、沙盘地面纹理和楼体挤出，并复用地标楼层及屋顶细节。两区新增建筑占地与高度均为示意；交通层开关在平面图和沙盘中生效。新区域默认打开平面图，以便核对交通照片；下城保留原先的视图状态。

## 更新方式

每套模型记录 region。重绘交通图数据或修改地标模板后，运行 `python3 scripts/build-gct-basemaps.py`（需要 Shapely 与 NumPy），更新三城区示意道路、街区、建筑轮廓和地标留白。输出记录交通数据、地标模板及生成脚本 SHA-256；相关测试阻止旧建筑数据配新地图。道路沿局部街区设计，楼块从街道边界向内布置，并排除绿地与地标占地。

`src/lib/gotham-plan.ts` 是平面 SVG 和沙盘的共同轮廓计算入口。`src/lib/gotham-roof-details.ts` 定义共享屋顶细节，平面图按高度排序绘制，以避免下层附属结构覆盖上层屋顶。`src/components/gotham-landmark-model.ts` 绘制建筑窗格、砖石纹理、檐口、屋顶与附属结构。改地标时避免在渲染组件中重复定义坐标。

体育馆使用低矮椭圆顶、径向肋架和采光顶；市政厅突出柱廊、山墙与双坡屋顶；GCPD 增加天台设备及无光束的信号灯；冰山俱乐部增加入口与顶层体块；谜语人公寓增加烟囱、屋顶窗和消防梯。街巷和街区保留原轮廓并补充屋面细节。窗格由小型 Canvas 纹理绘制，几何只用于轮廓和附属结构；几何、材质和纹理在卸载时释放。
